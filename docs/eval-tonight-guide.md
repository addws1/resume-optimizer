## 第 2 步：测试剧本（每个产品约 25 分钟）

按 **豆包 → Kimi → DeepSeek → Coze** 的顺序，每个产品把下面 5 个测试跑一遍。
（Coze 用官方商店里的通用助手类 Bot，把 Bot 名字记在打分表里保证可复现）

**每个测试都：先截图 → 存到 `docs/eval-evidence/`，命名如 `1.1-豆包.png` → 立刻在打分表填分数和一句话依据。**

### 测试 1.1（新开会话）

发送：

```
帮我看看这段经历写得行不行：

【粘贴材料 A】
```

看什么：它有没有**主动问你目标岗位**？（问了=5 分的关键特征；直接给泛泛建议=3 分）

### 测试 1.2（新开会话，连发 5 轮）

```
第1轮：我的目标岗位是 AI 产品实习生。下面是我的一段项目经历：【粘贴材料 A】
第2轮：这段经历里最大的问题是什么？
第3轮：帮我把成果部分加上量化表述
第4轮：语气再正式一点
第5轮：按我最开始说的岗位，把第一段再改一版
```

看什么：第 5 轮它还记得"AI 产品实习生"吗？改的是"第一段"吗？（两个都对=5；记得岗位但段落错=3；岗位忘了=1）

### 测试 1.3（不用发新消息）

回顾刚才两个会话，给"呈现体验"打分：输出是分点/表格还是大段糊字？能不能顺畅追问？

### 测试 4.1 + 4.2（新开会话）

```
我目标岗位是 AI 产品实习生，这是岗位 JD：

【粘贴材料 B】

请帮我优化这段项目经历：

【粘贴材料 A】
```

- 4.1 看：有没有用 STAR 结构？有没有建议加量化数据？有没有解释为什么这么改？
- 4.2 看同一个输出：JD 里的词（代码生成、Agent、数据分析）有没有被融进优化结果？有没有指出你的经历和 JD 的差距？

### 测试 4.3（新开会话）

```
我目标岗位是后端开发实习生，这是岗位 JD：

【粘贴材料 D】

请帮我优化这段项目经历：

【粘贴材料 A】
```

看什么：**把这个输出和 4.1 的输出并排对比**——换了个完全不同的岗位，它给的优化结果差异大吗？几乎一样 = 1 分（模板化实锤，这是你最想抓到的证据）。
