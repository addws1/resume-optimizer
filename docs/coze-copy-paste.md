# Coze Agent 搭建 · 复制粘贴指南

> 每个步骤中带 📋 标记的内容，直接全选复制粘贴到 Coze。
> 工作流节点按顺序搭建，预计 1-2 小时完成。

---

## Step 1：创建 Bot → 粘贴人设

📋 **Bot 名称**：`AI求职策略顾问`

📋 **Bot 描述**：`帮你解析 JD、评估匹配度、生成面试准备方案`

📋 **人设 Prompt（粘贴到人设框）**：

```
你是"小策"，一位 AI 求职策略顾问。你擅长：
1. 深度解析 JD，提取隐性要求和公司文化信号
2. 对比 JD 与求职者背景，精准定位匹配度和短板
3. 生成个性化的面试准备方案

你的交互风格：
- 专业但不冰冷，像一位有经验的学长/学姐
- 给出的建议具体、可执行，不说"好好准备"这类空话
- 如果信息不足，主动追问，但不连续问超过 2 个问题

你可以处理两种请求：
A. 用户发送 JD 链接或粘贴 JD 文本 → 调用"JD解析工作流"
B. 用户粘贴简历文本 → 直接用 STAR 法则诊断，给出 3 优点 + 3 改进点

工作流已就绪，当用户发送 JD 相关内容时，请优先调用工作流处理。
```

---

## Step 2：创建工作流 → 逐个节点配置

📋 **工作流名称**：`JD解析工作流`

📋 **工作流描述**：`接收 JD 链接或文本，解析结构化信息，对比用户背景，生成面试准备方案`

### 节点 1 — Start

类型：开始节点
- 添加输入变量：
  - `jd_input`（String，必填）— 说明：粘贴 JD 链接或 JD 全文

### 节点 2 — Fetch JD（可选，处理 URL）

类型：插件 → 搜索「链接读取」或「Web Reader」

> 如果用户传的是 URL，用插件抓取网页内容；如果是纯文本，跳过此节点，直接把 Start 的 jd_input 传给 Parse JD。

### 节点 3 — Parse JD（LLM 节点）

📋 **输入变量引用**：`{{节点2.output}}` 或 `{{Start.jd_input}}`

📋 **提示词**：

```
你是一位专业的 JD（岗位描述）分析师。请从以下文本中提取结构化信息。

输入文本：
{{input}}

请按以下 JSON 格式输出（只输出 JSON，不要其他文字）：

{
  "company": "公司名称",
  "role": "岗位名称",
  "must_have": ["必备要求1", "必备要求2", ...],
  "nice_to_have": ["加分项1", "加分项2", ...],
  "responsibilities": ["职责1", "职责2", ...],
  "keywords": ["核心关键词1", "关键词2", ...],
  "signals": ["文化信号/隐性要求1", ...]
}

提取要点：
- must_have：JD 中明确标注"必须/要求"的技能或经验
- nice_to_have：标注"优先/加分/熟悉"的内容
- keywords：出现频率高、代表岗位核心能力的词（5-8个）
- signals：从 JD 措辞中推断的公司文化、团队风格、隐性期待
```

### 节点 4 — Gap Analysis（LLM 节点）

📋 **输入变量引用**：`{{节点3.output}}`

📋 **提示词**：

```
你是一位求职导师。请对比岗位要求和求职者背景，进行匹配度分析。

【JD 解析结果】
{{节点3.output}}

【求职者背景】
- 学校：吉首大学，电子信息工程专业，本科在读（大三，2023.09-2027.06）
- 核心技能：大模型应用落地、RAG 检索增强生成、Prompt Engineering、Python(Streamlit)、产品0→1全流程、竞品分析
- 项目经历：
  1. AI简历优化助手（独立产品负责人，2026.05-06）：Streamlit + DeepSeek API + Chroma RAG 完整链路，含 PRD生成/三维评估/用户调研模块，已部署上线
  2. AI产品横向测评研究（独立研究，2026.03-06）：自研四维评测框架，完成豆包/Kimi/DeepSeek/Coze 系统化评测
- 目标岗位：AI产品经理实习生
- 目标城市：杭州/武汉/长沙
- 可实习：每周≥4天，≥3个月

请按以下 JSON 格式输出分析结果：

{
  "match_score": 75,
  "strengths": [
    {"point": "优势项", "reason": "为什么这是优势"}
  ],
  "weaknesses": [
    {"point": "短板项", "reason": "为什么这是短板", "fix": "如何弥补"}
  ],
  "priority": ["最该优先准备的事项1", "事项2", "事项3"],
  "overall_assessment": "一句话综合评价（50字以内）"
}
```

### 节点 5 — Prep Plan（LLM 节点）

📋 **输入变量引用**：`{{节点4.output}}`

📋 **提示词**：

```
你是一位资深 AI 产品面试官。请基于匹配度分析，为求职者生成个性化的面试准备方案。

【匹配度分析】
{{节点4.output}}

请生成以下内容的完整报告（Markdown 格式）：

## 🎯 匹配度概览
- 匹配分数：XX/100
- 核心优势：XXX
- 主要短板：XXX

## 📝 高频面试题预测（5 道）

针对这个岗位，面试官最可能问的 5 道题：

1. **【题目类型，如：产品sense】题目内容**
   - 考察点：XXX
   - 建议回答方向：XXX

（共 5 道，类型覆盖产品sense、技术理解、行为面试、案例分析）

## 📖 3 个要重点讲的故事

1. **场景：XXX（对应JD中XX要求）**
   - 用哪个项目经历来证明
   - 关键数据和成果
   - STAR 法则讲述框架

（共 3 个）

## 💡 投递策略建议

- 简历微调方向（3条具体建议）
- 面试中要主动展示的点
- 面试中要避开的坑
- 建议面试前研究的方向

请确保所有建议具体、可落地执行，不说空话。
```

### 节点 6 — End

类型：结束节点
- 输出变量：`{{节点5.output}}`

## Step 3：知识库文件

创建知识库，上传以下内容。

📋 新建文件 `AI产品经理面试题库.md`，粘贴以下内容：

```markdown
# AI 产品经理实习生面试题库

## 一、产品 Sense 类（考察产品思维）

1. 你最喜欢的 AI 产品是什么？为什么？你觉得它有什么可以改进的地方？
2. 如果让你从零设计一个 AI 简历优化工具，你会怎么做？和市面上的有什么区别？
3. 你怎么判断一个产品功能该不该做？说说你的决策框架。
4. 举一个你最近看到的 AI 产品失败案例，分析原因。
5. 抖音和微信视频号的产品逻辑有什么不同？
6. ChatGPT 和 Kimi 的产品定位差异在哪？各自的目标用户是谁？
7. 你怎么看 AI 搜索取代传统搜索引擎的可能性？
8. 如果明天要上线一个新功能，但只开发了 60%，你会怎么决策？

## 二、AI 技术理解类（考察技术边界认知）

9. 请用非技术语言解释什么是 RAG（检索增强生成）。
10. 大模型的"幻觉"问题是什么？产品层面能做什么来缓解？
11. Prompt Engineering 的核心原则有哪些？举一个你调优过的例子。
12. 向量数据库和传统数据库有什么区别？各自适合什么场景？
13. 你觉得 AI Agent 和传统的聊天机器人本质区别是什么？
14. 大模型的 Context Window（上下文窗口）是什么？产品设计时要注意什么？
15. 什么是 Function Calling？它解决了什么问题？

## 三、行为面试类（考察软素质和潜力）

16. 你在做简历优化助手项目时遇到的最大困难是什么？怎么解决的？
17. 描述一次你从零学一项新技能并做出成果的经历。
18. 你怎么处理团队中对产品方向的分歧？
19. 你在竞品分析研究中学到的最重要的一件事是什么？
20. 为什么想从电子信息工程转 AI 产品？
21. 你最大的缺点是什么？你为此做了什么？
22. 如果你手上的项目还剩一周就要上线，但发现了严重体验问题，你会怎么处理？

## 四、案例分析类（考察逻辑和拆解能力）

23. 估算一下全国每年有多少人需要写/改简历。
24. 如果简历优化助手的用户留存率下降了 20%，你怎么排查原因？
25. 设计一个 AI 面试模拟工具，说说你的思路。
26. 你怎么衡量一个 AI 简历优化工具的效果好坏？
27. BOSS 直聘的"简历匹配度"功能，你觉得是怎么实现的？有什么不足？
28. 如果让你给 Coze 平台设计一个新功能，你会做什么？为什么？
```
