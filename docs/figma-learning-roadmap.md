# Figma 学习路线 & 原型规格文档

> **目标**：用 3-5 天学会 Figma 基础，产出 3 个「AI 简历优化助手」页面原型
> **用途**：放入作品集，证明原型设计能力（当前简历列了墨刀/Axure 但无作品可展示）

---

## 一、3-5 天学习路线

### Day 1：Figma 基础操作（2-3 小时）

**目标**：能创建 Frame、添加文本和形状、使用 Auto Layout

| 时间 | 内容 | 资源 |
|------|------|------|
| 15min | 注册 Figma 账号（figma.com，免费版即可），下载桌面端或直接用网页版 | — |
| 30min | 看官方入门视频：Figma for Beginners | [YouTube 搜索 "Figma for Beginners"](https://www.youtube.com/results?search_query=figma+for+beginners) |
| 45min | 动手：创建 Frame（桌面/移动端尺寸）、添加矩形、文字、图片占位 | — |
| 30min | 学 Auto Layout：让元素自动排列和对齐（Figma 最核心功能） | 官方 Auto Layout 教程 |
| 30min | 动手：用 Auto Layout 做一个简单的卡片组件 | — |

**Day 1 产出**：一个包含标题、文字、按钮、图标的卡片组件

### Day 2：组件化思维（2-3 小时）

**目标**：学会组件（Components）+ 变体（Variants）

| 时间 | 内容 | 资源 |
|------|------|------|
| 30min | 学 Components：创建组件 → 复制实例 → 修改主组件同步更新 | 官方 Components 教程 |
| 30min | 学 Variants：同一组件的不同状态（如按钮的 hover/disabled/primary/secondary） | 官方 Variants 教程 |
| 30min | 动手：创建一组按钮组件（主按钮、次按钮、禁用态） | — |
| 30min | 学 Text Styles 和 Color Styles：建立设计系统的颜色和文字规范 | 官方 Styles 教程 |

**Day 2 产出**：一套基础组件库（按钮 x4、输入框 x2、标签 x3）

### Day 3：原型交互（2 小时）

**目标**：学会连线做页面跳转和交互动效

| 时间 | 内容 | 资源 |
|------|------|------|
| 30min | 学原型连线：Frame 之间的跳转、触发方式（点击/悬停） | 官方 Prototyping 教程 |
| 30min | 学 Overlay 和 Smart Animate：弹出层、平滑过渡动画 | 同上 |
| 30min | 动手：做 2 个页面 + 跳转交互 | — |

**Day 3 产出**：一个可点击跳转的两页原型

### Day 4-5：做 3 个完整页面原型（4-6 小时）

按下方规格做出「AI 简历优化助手」的 3 个关键页面。

## 二、3 个页面原型规格

> **2026-07-16 更新**：产品已上线免费额度 + BYOK 功能，页面 1 增加侧边栏规格、
> 页面 3 增加用户额度统计指标——原型与线上产品保持同步迭代（面试可讲这一点）。

### 页面 1：首页（优化输入页 + 侧边栏）

**设计目标**：简洁、聚焦，一眼看懂产品做什么；侧边栏承载模型切换与额度体系

```
┌─────────────┬────────────────────────────────────────────┐
│ ⚙️ 设置      │  📄 简历优化助手                            │
│             │  AI 驱动的简历优化 · 变成面试官想看的亮点     │
│ 🤖 LLM 后端  │ ────────────────────────────────────────── │
│ [deepseek ▾]│   ┌────────────────────────────────────┐   │
│             │   │  粘贴你的项目经历...                 │   │
│ 🔑 API 状态  │   │                                    │   │
│ ✓ 已配置     │   │  示例：用 Python + Django 写了      │   │
│             │   │  一个电商网站的后台管理系统…         │   │
│ 🎫 免费额度  │   └────────────────────────────────────┘   │
│ 优化 剩 2/3  │                                            │
│ PRD  剩 3/3 │   🎯 目标岗位:[______] 🏢 目标公司:[______] │
│             │                                            │
│ 🔐 自己的Key │   ☑️ 启用 RAG 知识增强（3 条知识已就绪）    │
│ [••••••••]  │                                            │
│ 填写后不限次 │   ┌──────────────────────────────┐         │
│             │   │        🚀 开始优化            │         │
│ ─────────── │   └──────────────────────────────┘         │
│ 📚 知识库    │                                            │
│ 3 个文档     │   💡 写作技巧：动作动词开头/量化数据/STAR   │
└─────────────┴────────────────────────────────────────────┘
```

**Figma 实现要点**：
- 页面 Frame：1440 x 900（桌面端 Web 应用）；左侧边栏固定 280px，深色 `#161b22`
- 侧边栏元素自上而下：模型下拉框 → API 状态徽章 → 额度展示 → BYOK 密码输入框 → 知识库入口
- **额度组件做 Variants 两个状态**：`有剩余`（灰字 caption）/ `已用完`（黄色 warning 条 + "填入自己的 API Key 可继续使用"）——这是展示组件化思维的好素材
- BYOK 输入框：password 型（圆点占位），下方一行小字"仅存会话内存，不落盘"
- 按钮：绿色渐变主按钮（CTA），圆角 8px，高度 48px
- 整体配色：暗色主题（`#0d1117` 背景 + `#161b22` 卡片 + `#c9d1d9` 正文字）

## 四、上手后的进阶

做完 3 个页面后，可以继续：

1. **加交互**：给按钮加点击跳转（首页「开始优化」→ 结果页，结果页「数据看板」→ 看板页）
2. **做移动端适配版**：同样的功能，做一个 375x812 的手机版页面（证明你有响应式思维）
3. **导出 PNG/PDF**：Figma → Export → PNG（2x），放入作品集
4. **录屏演示**：Figma Present 模式 → 用 OBS 或系统自带录屏录 1 分钟走查视频
5. **分享链接**：Figma 右上角 Share → "Anyone with the link can view" → 复制链接放入简历
