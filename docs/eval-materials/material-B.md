# 材料 B：目标岗位 JD（AI 产品实习生 · We0.ai）

## 职位描述

1. 参与代码生成和研发 Agent 的技术研究及产品设计。
2. 探索技术在提升研发效率和优化开发流程中的应用。
3. 跟进产品开发进度，确保按时高质量交付。
4. 分析用户数据和反馈，优化产品功能和用户体验。

## 任职要求

1. 计算机科学、软件工程、数据科学等相关专业的在读本科生或研究生。
2. 对 AI 产品或代码产品有兴趣，有相关项目经验者优先。
3. 具备基本的数据分析能力，愿意学习数据分析工具。
4. 了解主流产品，如 cursor、bolt.new、lovable 等。
5. 具备良好的沟通能力和团队合作精神。
