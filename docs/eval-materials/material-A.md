# 材料 A：原始项目经历（流水账版，评测统一输入）

我在学校期间自己做了一个 AI 简历优化的网站项目。一开始是因为我自己找实习改简历很麻烦，就想能不能用 AI 来帮忙改。我用 Python 写的，界面是用 Streamlit 做的，可以把简历内容粘贴进去，然后 AI 会帮你优化，还会给出一些修改的建议。后面我又加了一些功能，比如可以上传文档做知识库，这样 AI 改的时候可以参考这些资料，改得更专业一点。还做了一个打分的功能，AI 会给优化的结果打分，可以看到分数。另外还能生成 PRD 文档和做用户调研问卷。模型方面支持好几个，DeepSeek、通义千问还有本地的 Ollama 都可以用，可以自己切换。后来我把它部署到了网上，别人也可以访问使用。因为担心别人用太多把我的 API 额度用完，我还设计了一个免费次数的限制，用完了可以填自己的 Key 继续用。整个项目是我自己一个人做的，从有想法到上线大概花了两个月，中间也遇到了很多问题，都一个个解决了。这个项目让我学到了很多东西，对 AI 产品有了更深的理解。
