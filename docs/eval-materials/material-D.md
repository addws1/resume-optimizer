# 材料 D：对照岗位 JD（后端开发实习生 · 金融科技方向）

## 岗位职责

1. 协助老师完成交易系统、行情系统的辅助模块开发、功能测试与 Bug 修复，配合核心业务模块的迭代优化。
2. 参与数据处理相关工作，协助搭建简单的数据统计与分析脚本。
3. 协助整理技术文档、接口文档，参与代码评审环节的基础检查。
4. 配合构建监控与日志收集的辅助功能，协助排查简单的系统异常问题，提供基础定位支持。
5. 完成带教老师安排的其他技术辅助工作，在实践中提升后端开发相关技能。

## 任职要求

1. 计算机科学、软件工程等相关理工专业本科及以上学历，在校学生，能保证至少 3 个月全职实习。
2. 掌握 Python 编程语言，熟悉 Pandas、Numpy 等数据处理库的基础使用，具备简单的代码编写与调试能力。
3. 了解 SQL 基础语法，能够完成基础的数据库查询、数据提取与简单数据处理操作。
4. 对后端开发、金融科技领域有浓厚兴趣。
5. 工作认真负责、态度积极，具备良好的沟通能力和团队协作意识，服从带教老师安排。
