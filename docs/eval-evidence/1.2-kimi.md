**项目背景与需求洞察**

在求职实习过程中，观察到身边同学在简历修改环节存在共性痛点：缺乏针对目标岗位的优化思路，且修改后难以获得有效反馈。为验证需求，对 **20 余位**同学进行深度访谈，**80% 以上受访者**表示愿意为"岗位定向优化 + 量化反馈"功能付费或使用。基于此，独立策划并开发 AI 简历优化工具。

**产品设计与迭代**

- **MVP 阶段（第 1–2 周）**：聚焦核心闭环，上线"简历粘贴 → 岗位选择 → AI 优化 + 修改建议"功能，采用 Streamlit 快速搭建，**2 周内完成开发并交付 10 位种子用户**测试；

- **扩展阶段（第 6–8 周）**：针对用户求职场景延伸需求，新增 PRD 文档生成与用户调研问卷功能，产品定位由单一简历工具扩展为**求职辅助工具矩阵**。

**技术实现与商业化设计**

- 模型层支持 DeepSeek、通义千问及 Ollama 本地部署的多模型切换策略，覆盖不同用户的**成本敏感型与隐私敏感型**需求场景；
- 部署上线后，设计**免费额度 + 自有 API Key 双轨机制**，在保障用户体验的同时将单用户平均服务成本控制在 **0.3 元/次**以内。
