## 3. 功能需求

### 3.1 功能总览（当前 v3.0 已实现）

- **Tab 1 - 简历优化**：输入项目经历 + 目标岗位，AI 生成优化版，支持评分对比
- **Tab 2 - PRD 生成**：基于经历和 JD，自动生成一份标准 PRD
- **Tab 3 - 效果评估**：三维度打分（完整性/匹配度/格式），趋势折线图，CSV 导出
- **Tab 4 - 用户调研**：问卷录入、NPS 评分、痛点汇总
- **Tab 5 - 数据看板**：优化次数统计

### 3.2 核心功能详细说明

#### 3.2.1 简历优化（核心）
- **输入**：原始经历文本 + 目标岗位（可选）
- **处理流程**：RAG 检索相关知识 → 拼入 Prompt → LLM 生成 → JSON 解析 → 渲染
- **输出**：优化后的简历文案（带对比展示）+ 三维度评分
- **容错**：四层 JSON 解析降级（直接解析 → 代码块提取 → 正则修复 → 逐字段兜底）

#### 3.2.2 RAG 知识库增强
- **向量化方案**：TF-IDF（384维, 本地可用）/ BGE（512维, Sentence-Transformers）
- **检索策略**：向量语义 + TF-IDF 关键词双路召回 → 去重 → ReRank → Top-K
- **向量库**：Chroma
- **知识管理**：支持添加/删除/批量导入，含一键加载示例知识库

#### 3.2.3 多模型切换
- DeepSeek（默认）/ 通义千问 / Ollama（本机）
- 侧边栏一键切换，自动清除单例缓存
- 免费额度：每功能每人 3 次免费，超出需填自己的 API Key（BYOK）

#### 3.2.4 效果评估
- 三维度量化（完整性/岗位匹配度/格式规范度），0-5 分制
- 历史趋势折线图 + CSV 导出

#### 3.2.5 用户调研
- 标准化问卷录入（NPS + 痛点 + 建议）
- 本地 JSON 存储，自动汇总生成报告

## 5. 非功能性需求

### 5.1 性能
- 首页加载 ~1.2s（重型依赖 sklearn/chromadb/pandas 懒加载）
- LLM 请求响应取决于第三方 API，不做本地优化

### 5.2 安全
- API Key 通过 .env 加载，不硬编码
- 用户 IP 仅存 sha256 哈希，不落明文
- BYOK Key 仅存 session_state，不落盘

### 5.3 兼容性
- 浏览器：Chrome/Edge/Firefox 现代版本
- 部署：本地（streamlit run）/ Streamlit Cloud

## 6. 技术方案（概要）

| 层级 | 选型 | 选型理由 |
|------|------|---------|
| 前端框架 | Streamlit | Python 生态，快速搭建，满足 MVP 需求 |
| LLM | DeepSeek（默认） | 性价比高，中文理解好 |
| 向量库 | Chroma | 本地部署，零额外依赖 |
| Embedding | TF-IDF / BGE 双方案 | TF-IDF 无 GPU 也能跑，BGE 精度更高 |
| 分割策略 | Markdown 标题分割 | 比固定长度切 chunk 更语义完整 |
| 部署 | Streamlit Cloud | 免费，与 GitHub 联动 |
